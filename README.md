## Overview

QuietSocial is a native Android application designed to help users regain control over their screen time and reduce compulsive social media usage.

The project originated from a personal frustration with existing digital wellbeing tools: whenever I reached a screen-time limit, I could simply extend it and continue scrolling.

QuietSocial takes a different approach, helping users stick to the boundaries they set for themselves rather than offering an easy way to extend their limits.

## Key Features

- **Daily Screen-Time Limits:** Set individual and shared usage allowances for selected applications.
- **Limit Enforcement:** Redirect users away from restricted applications when their allowance is exhausted.
- **Short-Video Controls:** Restrict repetitive short-video swiping in supported applications.
- **Social Media Distraction Controls:** Restrict selected distracting sections of supported social platforms.
- **Night Protection:** Schedule periods during which selected applications are restricted.
- **Usage Monitoring:** Track daily usage and remaining allowances.

## Technology

- **Platform:** Android
- **Language:** Java
- **Android APIs:** Accessibility Service, Usage Stats API
